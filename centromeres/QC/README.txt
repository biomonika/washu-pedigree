# Quality Control of Assembled Centromeres

For each centromere participating in either the three-generational transmission (3G; grandparent->mother->granddaughter) or two-generational transmission (2G; grandparent->mother->not transmitted), we report the number of basepairs flagged by Flagger (flagger_v1.2.0; using HiFi and ONT reads) and Nucflag (0.3.6; using HiFi reads) in each generation. This analysis prompted us to remove chromosome four from the de-novo candidate mutation analysis.
